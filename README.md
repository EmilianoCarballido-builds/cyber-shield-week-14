# Cyber Shield MX · Week 14

[Live pricing](https://cyber-shield-week-14.vercel.app/pricing) · [10:1 memo](https://cyber-shield-week-14.vercel.app/about) · [Free planner](https://cyber-shield-week-14.vercel.app/plan)

Educational Spanish continuity planner for Mexican small-business owners without dedicated security staff. Free essentials, conditional MXN 299/business/month trial and hypothetical MXN 599 one-time fallback. Two segments: 1–5 and 6–25 people. No payment, active protection, monitoring, backups or restore happens in this demo.

Simulator: businesses × conversion × price -> monthly/annual gross revenue, full delivery costs, contribution, support target and capacity. Save up to five numeric scenarios with consent on this device; reload, load, delete and clear. Inputs/retention/costs are assumptions, not observations. The memo's hypothetical buyer example is 2.01:1; 10:1 is not demonstrated.

## Develop
Node 24, pnpm. `pnpm install --frozen-lockfile`, `pnpm dev`, `pnpm test`, `pnpm build`. No secrets or environment variables required. Vite + HTML/CSS/JS, deterministic engine, local scenario storage, Vercel. Optional inherited WebLLM on /plan downloads a model only with consent; default explanation is simulated. Pricing needs no AI calls. Model chunks are large but lazy-loaded.

Blueprint governs: ten-business conditional trial, support target <=15 minutes/account/month, actual witnessed backup restore, real paid renewal, all delivery costs and positive contribution. If repeat value, renewal or support fails, switch to one-time setup; pause on privacy harm or false assurance. Three paid commitments is only a test threshold. No interview, restore, payment or renewal is fabricated. Never publish personal research data or credentials.

Known limits: local scenario data is unencrypted on a shared device. No registry vulnerability audit in this environment. Buyer value and Mexican demand unverified. User must perform research, record video and confirm course submission/domain requirements. Build chronology and transcript coverage are stated honestly in the evidence files.
